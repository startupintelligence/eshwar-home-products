# Eshwar Home Products

**Website project by Quantora Digital (QD)**

## Overview

A product exploration website for Eshwar Home Products. Visitors can browse the product catalogue, learn about the business, and contact the shop.

## Website Sections

- Home and About
- Product Catalogue
- Location and Contact

## Planned Features

- Browse products by category
- View product information and optional prices
- Contact the shop through WhatsApp or email
- Responsive, mobile-friendly experience
- Client-managed product and contact updates

## Client Dashboard

The planned `/admin` dashboard will allow the authorised client to:

- Add and edit products
- Update prices and product images
- Save drafts and preview changes
- Publish website updates

## Planned Technology

- **GitHub Pages:** Public website hosting
- **Firebase Authentication:** Admin sign-in
- **Firebase Firestore:** Website content and settings
- **Firebase Storage:** Product images

Technology choices and integrations will be validated during implementation.

## Project Status

**Planning** — Development has not started. Features and integrations will be tested before launch.

## Project Scope

This is an informational product catalogue, not an e-commerce platform. It will not include a shopping cart, checkout, online payments, or online order processing.

## Ownership and Handover

Quantora Digital will manage development. The GitHub repository is planned to be transferred to the client after the website is completed and tested. The Firebase project will be created under the client's Google account from the beginning.

## Security Notes

- Never commit passwords, private keys, service-account files, or other credentials.
- Protect Firebase data with authentication and security rules.
- Public website content should only expose information intended for visitors.
