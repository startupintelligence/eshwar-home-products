# Store photo assets

Add only original photos supplied or approved by the store owner. Do not use reviewer-uploaded images or stock photos as store photos.

Suggested filenames for the site gallery:
- `storefront.webp` — exterior and signboard
- `millets-shelf.webp` — millet and grain shelves
- `chekku-oils.webp` — cold-pressed oil display
- `snacks-pantry.webp` — snacks and pantry shelves

Recommended export: 800 × 600 px WebP, ideally below 75 KB each. Keep the original files separately. The site should not reference a photo until that file exists in this folder.
