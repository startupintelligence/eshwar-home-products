# Public image assets

- `placeholders/` contains temporary, clearly labelled category illustrations only.
- Add client-approved product/store photographs only after the client supplies or approves them.
- Do not imply a category illustration depicts a specific product, brand, package, certification, or stock status.
- Keep image frames at 4:3 and retain intrinsic `width` and `height` attributes when replacing assets.
- Optimise approved raster photos to WebP before committing. Keep temporary category SVGs crisp and lightweight.
